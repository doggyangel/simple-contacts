# simple-contact-cli

simple-contact-cli is a command line based contact manager.

## Why I made this

This was my first project that I actually worked on for a considerable amount of time. I really only did it as a challenge/learning tool. I hope that if anyone downloads this, they find it useful or at least well made.

## Installation

Clone the repository:
```bash
git clone https://github.com/doggyangel/simple-contacts.git
pip install simple-contacts
```

## Usage

Run the program directly from your terminal.

```bash
contacts
```
